Create an Episode

POSTs to /episodes via HTMX (JSON-encoded). The endpoint detects HX-Request and returns an HTML fragment, swapped into the result panel below.

Each host has a name and an email. Click "+ Add host" to enter more than one.
Each presenter has a name and an email. Click "+ Add presenter" to enter more than one. Stored under the Episode's guests collection (the entity's name for the second cast list).
